# rmx-mower-gateway

Firmware for the mower's gateway: its LTE link to the server. Experiments and diagnostics come first in [rmx-mower-gateway-probe](https://github.com/rmx-lt/rmx-mower-gateway-probe).

Part of [Blade of Grass](https://github.com/rmx-lt/blade-of-grass), a robotic lawn mower project. Docs are in the [wiki](https://github.com/rmx-lt/blade-of-grass/wiki).
